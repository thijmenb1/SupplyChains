## Resource flow

### raw resources
- mine (on iron ore) -> iron ore
- mine (on copper ore) -> copper ore
- mine (on gold ore) -> gold ore
- mine (on sand) -> sand
- mine (on stone) -> gravel
- pumpjack -> crude oil
### procesed
- iron ore -> blast furnace -> iron bar -> steelmill -> steel bar
- copper ore -> blast furnace -> copper ingots -> wiremill -> copper wire
- gold ore -> blast furnace -> gold ingots -> wiremill -> gold wire
- crude oil -> refinary -> fuel and asphalt
- gravel and sand -> cement mixer -> cement


## Routes
### To create a route:
1. Open the route ui
2. Press new route
3. select a source factory
4. select a destination factory
5. select the resource you want to deliver
### To assign a route:
1. click on the vehicle you want to assign a route too
2. click on the route icon
3. select the route you want to assign it to

## construction
